# 数据治理制度模板

> 适用：编写数据标准、质量、分类分级、资产、共享等专项管理办法。按“目的—范围—职责—流程—考核—附则”组织。

## 第一章 总则

**第一条（目的）** 为规范 `<业务域>` 数据管理，提升数据质量，保障数据安全，促进数据共享利用，制定本办法。

**第二条（依据）** 依据《数据安全法》《个人信息保护法》、`<行业规范/国家标准>` 及本单位制度。

**第三条（范围）** 适用于 `<系统/表/字段>` 的采集、存储、加工、共享、归档、销毁全生命周期。

**第四条（原则）** 业务主导、标准先行、源头治理、分级保护、以用促治、可度量可验收。

## 第二章 组织与职责

| 角色 | 职责 |
| --- | --- |
| 数据治理委员会 | 审定制度与年度计划，裁决跨部门争议 |
| 数据 Owner | 对数据内容、质量、共享范围负最终责任 |
| 数据 Steward | 维护标准、规则、目录、台账，组织整改复检 |
| 技术团队 | 实现采集、加工、脱敏、监控，保障稳定运行 |
| 安全合规岗 | 审核分级、共享、个人信息保护措施 |
| 使用方 | 按授权使用，反馈问题，不得转供 |

## 第三章 管理流程

### 3.1 标准管理

1. 需求提出 → 2. 复用检索 → 3. 起草 → 4. 评审 → 5. 发布 → 6. 落标检查 → 7. 季度复核。

### 3.2 质量管理

1. 规则制定 → 2. 监测扫描 → 3. 问题定位 → 4. 工单派发 → 5. 整改 → 6. 复检验收 → 7. 复盘。

### 3.3 分类分级与共享

1. 字段定级 → 2. 安全评审 → 3. 共享申请 → 4. 脱敏 → 5. 残留扫描 → 6. 授权交付 → 7. 到期回收。

### 3.4 资产登记

1. 上线前登记 → 2. Owner 确认 → 3. 质量评估 → 4. 发布资产卡片 → 5. 季度价值评估 → 6. 归档/下架。

## 第四章 考核

| 指标 | 目标 | 统计周期 |
| --- | ---: | --- |
| 核心数据质量达标率 | `<≥ 90%>` | 月 |
| 质量问题处置率 | `<≥ 85%>` | 月 |
| 资产登记完整率 | `100%` | 季 |
| 分类分级覆盖率 | `100%` | 季 |
| 共享残留 | `0` | 月 |

考核结果纳入部门绩效；连续两季度未达标的，提交数据治理委员会。

## 第五章 附则

**第 X 条** 本办法由 `<数据治理委员会>` 负责解释。

**第 X 条** 本办法自 `<YYYY-MM-DD>` 起施行。

**附件**：数据标准清单、质量规则清单、分类分级清单、资产台账、整改工单模板。

---

## 编写提示

1. 每条制度都要能回答“谁、做什么、什么时候、交付什么、怎么验收”；
2. 避免“加强”“推进”“提升”等无法考核的表述；
3. 与现有制度冲突时，先修订再发布；
4. 制度发布后 3 个月内做一次执行检查，否则容易变成“抽屉文件”。
